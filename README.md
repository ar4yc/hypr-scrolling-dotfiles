## Hyprland Dotfiles -- Scrolling layout

### Used:
* Dock - Waybar
* Power Panel - WLogout
* Wallpapers - SwayBG, Waytrogen
* Visualisator - Xava
* Volume Control - Qt-Pavucontrol
* Bluetooth Manager - Overskride
* ClipBoard - wl-clipboard + rofi
* Terminal - Kitty
* File Manager - Dolphin
* App launcher - Rofi
